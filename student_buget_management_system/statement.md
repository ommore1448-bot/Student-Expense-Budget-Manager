# Student Expense & Budget Management System

## 1. Problem Statement

Students often make multiple small expenses on food, transportation, education, entertainment, shopping, subscriptions, and other activities. When these transactions are recorded separately or not tracked properly, it can become difficult to understand total spending, remaining budget, and savings.

A simple transaction recording system can store expenses, but students also need basic analysis to understand where their money is being spent and whether their spending is within a planned budget.

The **Student Expense & Budget Management System** addresses this problem by providing a Python-based system for recording income and expenses, managing a monthly budget, analyzing spending patterns, and generating a financial summary.

---

## 2. Scope

The scope of the project includes:

- Recording income and expense transactions.
- Assigning categories to transactions.
- Viewing all stored transactions.
- Searching transactions by date, category, or type.
- Editing existing transactions.
- Deleting transactions.
- Setting a monthly budget.
- Calculating total expenses and remaining budget.
- Calculating total income and savings.
- Performing category-wise expense analysis.
- Identifying highest and lowest expenses.
- Generating a financial report.
- Validating user input.
- Saving and loading transaction data using a CSV file.

The project does not include real banking services, payment processing, financial advice, or connections to external financial systems.

---

## 3. Target Users

The primary target users are:

- College and university students.
- Students managing a fixed monthly allowance.
- Students who want to monitor personal spending.
- Students who want a simple way to understand their income, expenses, budget, and savings.

## 4. High-Level Features

### Transaction Management
- Add income.
- Add expenses.
- View transactions.
- Search transactions.
- Edit transactions.
- Delete transactions.

### Budget Management
- Set monthly budget.
- Calculate budget usage.
- Calculate remaining budget.
- Display budget status.

### Financial Analysis
- Calculate total income.
- Calculate total expenses.
- Calculate net savings.
- Calculate savings percentage.
- Calculate category-wise expenses.
- Find highest and lowest expenses.
- Find the highest spending category.

### Financial Reporting
- Generate a consolidated financial report.
- Display income and expense summaries.
- Display budget information.
- Display category-wise spending.

### Data Management
- Save transactions to a CSV file.
- Load transactions when the application starts.
- Handle missing and invalid stored records.

### Input Validation
- Validate dates.
- Validate amounts.
- Validate categories.
- Validate descriptions.
- Validate transaction types.
- Handle invalid user input.
